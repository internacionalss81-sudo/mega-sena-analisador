# Mega Analyzer

App Android em Python + Kivy para análise estatística e geração de jogos da Mega-Sena.

A pontuação 0-100 é apenas um índice interno. Ela não representa 80% de chance de ganhar e não prevê sorteios.

## GitHub

1. Crie um repositório.
2. Envie estes arquivos.
3. Abra Actions.
4. Selecione Build Android APK.
5. Clique Run workflow.
6. Abra a execução concluída.
7. Em Artifacts, baixe MegaAnalyzer-APK.
